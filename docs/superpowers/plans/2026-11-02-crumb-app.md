# Crumb on the Desktop (Plan 2 of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `Crumb.app` that puts the 3D black puppy on the desktop: transparent, click-through except on the puppy, wandering along the Dock with a distance-locked walk, poses, blinking, breathing and floppy ears, and a click menu with Quit.

**Architecture:** Three pure, tested pieces join `CrumbCore`: `ScreenMap` (screen points ↔ world metres), `Pose` (joint angles plus blending) and `Gait`/`Spring` (walk and ear physics). A new executable target `Crumb` renders `art/crumb.usdz` with RealityKit in a full-screen borderless window at desktop-icon level +1, through an orthographic camera so 1 m is always exactly 92 pt. `PuppetRig` maps a `Pose` onto the model's named pivots. `Pet` runs the per-frame loop with a temporary random wander. `scripts/make-app.sh` assembles and ad-hoc signs `build/Crumb.app`. **Plan 3** adds the brain and the Finder wiring: PetBrain, FolderWatcher, the FileFacts scanner, FinderBridge, the ask bubble, bites and belly visuals.

**Tech Stack:** Swift 6, SPM, Swift Testing, AppKit, RealityKit (`ARView`, `OrthographicCameraComponent`), macOS 15+, Xcode 27.2, Blender 4.x (art export only).

**Spec:** `docs/superpowers/specs/2026-11-02-crumb-desktop-pet-design.md` (Task 7 brings its art and architecture sections in line with this plan)

## Read this first

- **Everything here was built and run before the plan was written.** The code blocks are the verified files. All 9 tests pass, the app renders every pose, and the `.app` loads its model from `Contents/Resources`.
- **Tests need Xcode** (`xcode-select -p` → `/Applications/Xcode.app/Contents/Developer`). "Red" in TDD means a compile error (`cannot find 'X' in scope`). Keep one `@Test` per test file.
- **Facts measured in the render spike** (don't re-derive them):
  - `ARView` with `environment.background = .color(.clear)` in a borderless window with `isOpaque = false` and `backgroundColor = .clear` renders with a **transparent background**: the snapshot's alpha is 0 outside the puppy.
  - `OrthographicCameraComponent.scale` is **half the visible height in metres**. With scale 2 on a 1080 pt screen, 1 m = 270 pt, and the model's centre and top landed on the predicted pixel ±1.
  - **The loaded USDZ's top entity holds the Z-up → Y-up rotation** (orientation −90° about X). Setting `orientation` on it lays the dog on its back. Wrap it in a container entity and turn that (`PuppetRig.entity`).
  - **Joint axes** are each pivot's Blender-local axes (Z up, dog faces −Y): X pitch (+ opens the jaw, + nods the head down, + swings a foot backward, − tips the body's front up), Y roll (+ tilts the head), Z yaw (+ wags the tail). Turning the container +0.6 rad about world Y turns the puppy to face screen-right.
  - The model is about 0.92 m wide and 1.2 m tall, feet at y ≈ 0.
- **Checking visuals without eyes:** `ARView.snapshot` captures the render without Screen Recording permission (`screencapture` fails in this environment). `CRUMB_SNAPSHOT=<dir>` makes the app write one PNG per pose and quit. A subagent can `Read` those PNGs to check them.
- **Coordinates:** "screen points" always means top-left origin, y down, the same as Finder's `desktop position`. AppKit's bottom-left coordinates appear only inside `PetOverlay`, where they are converted.

```swift
import CoreGraphics

/// Converts between screen points (top-left origin, y down: Finder's desktop coordinates)
/// and the overlay's world plane (metres, origin at the screen centre, y up) seen by an orthographic camera.
public struct ScreenMap: Equatable, Sendable {
    public let width: Double
    public let height: Double
    public let pointsPerMeter: Double

    public init(width: Double, height: Double, pointsPerMeter: Double) {
        self.width = width
        self.height = height
        self.pointsPerMeter = pointsPerMeter
    }

    /// Value for `OrthographicCameraComponent.scale`: half the visible height, in metres.
    public var cameraScale: Float { Float(height / 2 / pointsPerMeter) }

    public func world(_ p: CGPoint) -> SIMD2<Float> {
        SIMD2(Float((p.x - width / 2) / pointsPerMeter), Float((height / 2 - p.y) / pointsPerMeter))
    }

    public func screen(_ w: SIMD2<Float>) -> CGPoint {
        CGPoint(x: width / 2 + Double(w.x) * pointsPerMeter, y: height / 2 - Double(w.y) * pointsPerMeter)
    }
}
```

```swift
/// Joint angles (radians) added to the model's rest pose. Axes are each pivot's local axes
/// from Blender (Z up, dog faces -Y), checked in RealityKit:
/// - X (pitch): + opens the jaw, + nods the head down, + swings a foot backward, - tips the body's front up.
/// - Y (roll): + tilts the head.
/// - Z (yaw): + turns the head, wags the tail.
public struct Pose: Hashable, Sendable {
    public var bodyPitch: Float = 0  // BodyPivot X; pivots at the rear feet
    public var bodyDrop: Float = 0  // BodyPivot moved down, metres (lying down)
    public var headPitch: Float = 0  // HeadPivot X
    public var headTilt: Float = 0  // HeadPivot Y
    public var headTurn: Float = 0  // HeadPivot Z
    public var jaw: Float = 0  // JawPivot X
    public var tail: Float = 0  // TailPivot Z
    public var legFront: Float = 0  // LegFL/LegFR X
    public var legBack: Float = 0  // LegBL/LegBR X
    public var eyeOpen: Float = 1  // EyeL/EyeR Z scale

    public init() {}

    static var joints: [WritableKeyPath<Pose, Float>] {
        [\.bodyPitch, \.bodyDrop, \.headPitch, \.headTilt, \.headTurn, \.jaw, \.tail, \.legFront, \.legBack, \.eyeOpen]
    }

    public static func mix(_ a: Pose, _ b: Pose, _ t: Float) -> Pose {
        var out = a
        for k in joints { out[keyPath: k] = a[keyPath: k] + (b[keyPath: k] - a[keyPath: k]) * t }
        return out
    }
}

public enum PoseName: String, CaseIterable, Sendable {
    case stand, sitTilt, sniff, bite, carry, sleep, burp

    // Starting values; tune by eye with `CRUMB_SNAPSHOT` (see scripts/snapshot-poses.sh).
    public var pose: Pose {
        var p = Pose()
        switch self {
        case .stand:
            break
        case .sitTilt:
            // Tipping the front up lifts the front paws; dropping the body puts them back down and sinks the hips.
            p.bodyPitch = -0.3
            p.bodyDrop = 0.14
            p.legFront = 0.3
            p.legBack = -1.2
            p.headPitch = 0.25
            p.headTilt = 0.35
        case .sniff:
            p.headPitch = 0.55
            p.legFront = -0.15
            p.tail = 0.2
        case .bite:
            p.headPitch = 0.45
            p.jaw = 0.55
        case .carry:
            p.headPitch = -0.1
            p.jaw = 0.15
        case .sleep:
            p.bodyDrop = 0.12
            p.legFront = -1.3
            p.legBack = 1.3
            p.headPitch = 0.45
            p.eyeOpen = 0.1
        case .burp:
            p.headPitch = -0.35
            p.jaw = 0.45
            p.eyeOpen = 0.4
        }
        return p
    }
}
```

`joints` is a computed property on purpose: a `static let` array of key paths fails Swift 6's concurrency check (`WritableKeyPath` isn't `Sendable`).

```swift
/// Walking in screen points. The walk cycle advances with distance covered, not time, so feet never slide.
public struct Gait: Sendable {
    public static let speed = 70.0  // points per second
    public static let stride = 36.0  // points per full leg cycle

    public var position: SIMD2<Double>
    public var target: SIMD2<Double>
    /// 0..<1 through the leg cycle.
    public private(set) var phase = 0.0
    /// +1 facing right, -1 facing left; the last horizontal direction walked.
    public private(set) var facing = 1

    public init(at p: SIMD2<Double>) {
        position = p
        target = p
    }

    public var isWalking: Bool { position != target }

    /// Moves toward the target; returns the distance covered.
    public mutating func step(_ dt: Double) -> Double {
        let delta = target - position
        let dist = (delta * delta).sum().squareRoot()
        guard dist > 0 else { return 0 }
        let move = min(dist, Self.speed * dt)
        position = move == dist ? target : position + delta * (move / dist)
        if delta.x != 0 { facing = delta.x > 0 ? 1 : -1 }
        phase = (phase + move / Self.stride).truncatingRemainder(dividingBy: 1)
        return move
    }
}

/// Damped spring for floppy parts (ears). Sub-steps so long frames stay stable.
public struct Spring: Sendable {
    public var value: Float = 0
    public var velocity: Float = 0
    public var stiffness: Float = 140
    public var damping: Float = 9

    public init() {}

    public mutating func step(toward target: Float, dt: Double) {
        var left = Float(dt)
        while left > 0 {
            let h = min(left, 1.0 / 120)
            velocity += ((target - value) * stiffness - velocity * damping) * h
            value += velocity * h
            left -= h
        }
    }
}
```

```swift
import CrumbCore
import RealityKit

/// Drives the joints of crumb.usdz from a Pose.
@MainActor
final class PuppetRig {
    /// Place and turn this. The model's own top entity holds the Z-up → Y-up rotation, so never overwrite that one.
    let entity = Entity()
    private var joints: [String: Entity] = [:]
    private var rest: [String: Transform] = [:]

    static let names = [
        "Body", "BodyPivot", "HeadPivot", "JawPivot", "TailPivot",
        "LegFL", "LegFR", "LegBL", "LegBR", "EarL", "EarR", "EyeL", "EyeR",
    ]

    struct MissingJoint: Error { let name: String }

    init(model: Entity) throws {
        entity.addChild(model)
        for name in Self.names {
            guard let joint = model.findEntity(named: name) else { throw MissingJoint(name: name) }
            joints[name] = joint
            rest[name] = joint.transform
        }
    }

    /// - swing: walk-cycle leg angle; diagonal pairs move together.
    /// - yaw: whole-body turn; + faces screen right.
    /// - ears: + flops both ears backward.
    /// - breath: belly scale offset.
    func apply(_ p: Pose, swing: Float, yaw: Float, ears: Float, breath: Float) {
        entity.orientation = simd_quatf(angle: yaw, axis: [0, 1, 0])
        set("BodyPivot", turn(p.bodyPitch, x), move: [0, 0, -p.bodyDrop])
        set("HeadPivot", turn(p.headPitch, x) * turn(p.headTilt, y) * turn(p.headTurn, z))
        set("JawPivot", turn(p.jaw, x))
        set("TailPivot", turn(p.tail, z))
        set("LegFL", turn(p.legFront + swing, x))
        set("LegBR", turn(p.legBack + swing, x))
        set("LegFR", turn(p.legFront - swing, x))
        set("LegBL", turn(p.legBack - swing, x))
        set("EarL", turn(ears, x))
        set("EarR", turn(ears, x))
        set("EyeL", scale: [1, 1, p.eyeOpen])
        set("EyeR", scale: [1, 1, p.eyeOpen])
        set("Body", scale: [1 + breath, 1, 1 + breath])
    }

    private let x: SIMD3<Float> = [1, 0, 0], y: SIMD3<Float> = [0, 1, 0], z: SIMD3<Float> = [0, 0, 1]

    private func turn(_ angle: Float, _ axis: SIMD3<Float>) -> simd_quatf { simd_quatf(angle: angle, axis: axis) }

    private func set(
        _ name: String, _ rotation: simd_quatf = simd_quatf(ix: 0, iy: 0, iz: 0, r: 1),
        move: SIMD3<Float> = .zero, scale: SIMD3<Float> = .one
    ) {
        guard let joint = joints[name], let base = rest[name] else { return }
        joint.transform = Transform(
            scale: base.scale * scale, rotation: base.rotation * rotation, translation: base.translation + move)
    }
}
```

```swift
import CrumbCore
import Foundation

/// Per-frame puppy behaviour. For now it just wanders along the Dock; Plan 3's PetBrain takes over the decisions.
@MainActor
final class Pet {
    let rig: PuppetRig
    let map: ScreenMap
    /// Screen y of the feet line: just above the Dock.
    let groundY: Double
    var gait: Gait
    /// The pose it is easing toward while standing still.
    var goal = PoseName.stand
    /// false freezes the wander decisions (snapshot mode, and later PetBrain).
    var autopilot = true

    private var pose = Pose()
    private var yaw: Float = 0
    private var stepAmount: Float = 0
    private var ears = Spring()
    private var clock = 0.0
    private var nextDecision = 2.0
    private var nextBlink = 3.0

    /// The model is about 0.92 m wide and 1.2 m tall with its feet at the origin.
    static let size = (width: 0.92, height: 1.2)

    init(rig: PuppetRig, map: ScreenMap, groundY: Double) {
        self.rig = rig
        self.map = map
        self.groundY = groundY
        gait = Gait(at: SIMD2(map.width * 0.3, groundY))
    }

    /// Screen rect (top-left origin) the puppy occupies; clicks inside it reach the pet.
    var frame: CGRect {
        let w = Self.size.width * map.pointsPerMeter, h = Self.size.height * map.pointsPerMeter
        return CGRect(x: gait.position.x - w / 2, y: gait.position.y - h, width: w, height: h)
    }

    func update(dt: Double) {
        clock += dt
        _ = gait.step(dt)
        if autopilot, !gait.isWalking, clock >= nextDecision { wander() }

        let ease = { (rate: Double) in Float(1 - exp(-dt * rate)) }
        pose = Pose.mix(pose, gait.isWalking ? PoseName.stand.pose : goal.pose, ease(6))
        // Three-quarter view while walking, face the viewer when still.
        yaw += ((gait.isWalking ? Float(gait.facing) * 0.6 : 0) - yaw) * ease(8)
        stepAmount += ((gait.isWalking ? 0.45 : 0) - stepAmount) * ease(10)
        ears.step(toward: gait.isWalking ? 0.35 : 0, dt: dt)

        var shown = pose
        if clock >= nextBlink {
            shown.eyeOpen = min(shown.eyeOpen, 0.1)
            if clock >= nextBlink + 0.15 { nextBlink = clock + .random(in: 2.5...6) }
        }
        rig.apply(
            shown,
            swing: stepAmount * sin(Float(gait.phase) * 2 * .pi),
            yaw: yaw,
            ears: ears.value,
            breath: 0.015 * sin(Float(clock) * 2.2))
        let feet = map.world(CGPoint(x: gait.position.x, y: gait.position.y))
        rig.entity.position = SIMD3(feet.x, feet.y, 0)
    }

    // ponytail: random stroll/sit/sniff; PetBrain (Plan 3) replaces this with real jobs.
    private func wander() {
        switch Double.random(in: 0..<1) {
        case ..<0.6:
            goal = .stand
            gait.target = SIMD2(.random(in: 80...(map.width - 80)), groundY)
            nextDecision = clock + .random(in: 1...3)  // counted from now; checked again once it arrives
        case ..<0.85:
            goal = .sitTilt
            nextDecision = clock + .random(in: 3...7)
        default:
            goal = .sniff
            nextDecision = clock + .random(in: 2...4)
        }
    }

    /// Snap straight to a pose (snapshot mode). "walk" starts a stroll to the right instead.
    func show(_ name: String) {
        if let p = PoseName(rawValue: name) {
            gait.target = gait.position
            goal = p
            pose = p.pose
        } else {
            goal = .stand
```

```swift
import AppKit
import Combine
import CrumbCore
import RealityKit

/// The puppy's window: borderless, transparent, covering the main screen just above the desktop icons.
/// Clicks pass through everywhere except on the puppy.
@MainActor
final class PetOverlay {
    /// Points per metre: the 1.2 m model ends up about 110 pt tall.
    static let pointsPerMeter = 92.0

    let window: NSWindow
    let view: PetView
    let pet: Pet
    private var updates: Cancellable?

    init(screen: NSScreen, model: Entity) throws {
        let size = screen.frame.size
        let map = ScreenMap(width: size.width, height: size.height, pointsPerMeter: Self.pointsPerMeter)
        // visibleFrame.minY is the Dock's height when the Dock is at the bottom (AppKit's y points up).
        let groundY = size.height - (screen.visibleFrame.minY - screen.frame.minY) - 6

        window = NSWindow(contentRect: screen.frame, styleMask: .borderless, backing: .buffered, defer: false)
        window.isOpaque = false
        window.backgroundColor = .clear
        window.hasShadow = false
        window.ignoresMouseEvents = true
        window.level = NSWindow.Level(rawValue: Int(CGWindowLevelForKey(.desktopIconWindow)) + 1)
        window.collectionBehavior = [.canJoinAllSpaces, .stationary, .ignoresCycle]

        view = PetView(frame: NSRect(origin: .zero, size: size))
        view.environment.background = .color(.clear)
        window.contentView = view

        let anchor = AnchorEntity(world: .zero)
        view.scene.addAnchor(anchor)
        let camera = Entity()
        var lens = OrthographicCameraComponent()
        lens.scale = map.cameraScale
        camera.components.set(lens)
        camera.position = [0, 0, 10]
        anchor.addChild(camera)
        let light = DirectionalLight()
        light.light.intensity = 3000
        light.look(at: .zero, from: [1, 2, 2], relativeTo: nil)
        anchor.addChild(light)

        let rig = try PuppetRig(model: model)
        anchor.addChild(rig.entity)
        pet = Pet(rig: rig, map: map, groundY: groundY)

        let menu = NSMenu()
        menu.addItem(withTitle: "Quit Crumb", action: #selector(NSApplication.terminate(_:)), keyEquivalent: "q")
        view.menu = menu

        updates = view.scene.subscribe(to: SceneEvents.Update.self) { [weak self] event in
            MainActor.assumeIsolated { self?.tick(dt: event.deltaTime) }
        }
        window.orderFrontRegardless()
    }

    private func tick(dt: Double) {
        pet.update(dt: dt)
        // Take clicks only while the mouse is over the puppy. AppKit's mouse y points up; the pet's frame is top-left.
        let mouse = NSEvent.mouseLocation
        let topLeft = CGPoint(x: mouse.x - window.frame.minX, y: window.frame.maxY - mouse.y)
        window.ignoresMouseEvents = !pet.frame.contains(topLeft)
    }

    /// Writes one PNG per pose (plus "walk") into `dir`, cropped around the puppy, then quits.
    func snapshotPoses(to dir: URL) async throws {
        try FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        pet.autopilot = false
        for name in PoseName.allCases.map(\.rawValue) + ["walk"] {
            pet.show(name)
            try await Task.sleep(for: .milliseconds(name == "walk" ? 900 : 600))
            let image: NSImage? = await withCheckedContinuation { done in
                view.snapshot(saveToHDR: false) { done.resume(returning: $0) }
            }
            guard let image, var cg = image.cgImage(forProposedRect: nil, context: nil, hints: nil) else { continue }
            let px = Double(cg.width) / pet.map.width
            let r = pet.frame.insetBy(dx: -30, dy: -30)
            if let crop = cg.cropping(to: CGRect(x: r.minX * px, y: r.minY * px, width: r.width * px, height: r.height * px)) {
                cg = crop
            }
            let png = NSBitmapImageRep(cgImage: cg).representation(using: .png, properties: [:])
            try png?.write(to: dir.appendingPathComponent(name + ".png"))
        }
        NSApp.terminate(nil)
    }
}

/// Shows the pet menu on click.
final class PetView: ARView {
    override func mouseDown(with event: NSEvent) {
        if let menu { NSMenu.popUpContextMenu(menu, with: event, for: self) }
    }
}
```
